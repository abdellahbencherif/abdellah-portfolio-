Open index.html in a browser to preview the website.
To publish, upload index.html, style.css, script.js, and the assets/ folder to any static website host (Netlify, GitHub Pages, etc.).

IMPORTANT PRIVACY NOTE:
The private_documents/ folder contains original scans with sensitive personal information. DO NOT upload that folder to a public website. The website itself only shows professional credential summaries.

TO ADD YOUR CV LATER:
1. Save your public-safe CV PDF as assets/abdellah-cv.pdf.
2. In index.html, find the two elements inside class="resume-actions".
3. Replace them with:
   <a class="btn primary" href="assets/abdellah-cv.pdf" target="_blank" rel="noopener">View CV ↗</a>
   <a class="btn secondary" href="assets/abdellah-cv.pdf" download>Download CV ↓</a>
